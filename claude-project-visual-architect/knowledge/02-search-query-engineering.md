# SEARCH QUERY ENGINEERING

How to construct YouTube and general search queries that land the exact clip in the first two results. This is the skill that separates an editor-grade recommendation from a useless one.

---

## THE EDITOR-GRADE QUERY FORMULA

Every YouTube search query must contain, in some combination, these four elements:

```
[SUBJECT] + [SPECIFIC SCENE DESCRIPTOR] + [QUALITY / FORMAT TAG] + [SOURCE / CHANNEL HINT]
```

**Example:**
- Bad: `Breaking Bad death`
- Mediocre: `Gus Fring death scene`
- Editor-grade: `Gus Fring Face Off death scene 1080p bomb nursing home`

The editor-grade version contains:
- Subject: `Gus Fring`
- Specific scene descriptor: `Face Off`, `bomb nursing home`
- Quality tag: `1080p`
- Implicit source hint: `Face Off` is the episode title, which creators use in upload titles

## QUERY RECIPES BY SITUATION

### Recipe 1 — Specific Character Scene
`[Character Name] + [Emotion/Action] + [Film/Show/Game Title] + [Quality]`

Examples:
- `Tony Stark I am Iron Man snap Endgame 4K`
- `Walter White I am the one who knocks scene 1080p`
- `Kratos Atreus argument Ragnarok cutscene 4K`

### Recipe 2 — Finding Scene Packs
`[Title] + "scene pack" + [optional: character or resolution]`

Examples:
- `Breaking Bad scene pack Walter White 1080p`
- `Attack on Titan Eren scene pack 4K`
- `Joker 2019 scene pack Arthur Fleck`

### Recipe 3 — Twixtor / Slow-Mo Edits
`[Character/Title] + "twixtor" + [optional: "4K", "raw", "no music"]`

Examples:
- `Naruto vs Sasuke twixtor 4K raw no music`
- `Spider-Man No Way Home twixtor final swing`
- `Demon Slayer Hinokami twixtor Tanjiro 4K`

### Recipe 4 — Full Cutscene Compilations (Games)
`[Game Title] + "all cutscenes" + [optional: "no commentary", "4K", "game movie"]`

Examples:
- `God of War Ragnarok all cutscenes 4K no commentary`
- `The Last of Us Part 2 all cutscenes game movie`
- `Red Dead Redemption 2 all cutscenes no commentary 4K`

### Recipe 5 — Character-Specific Compilations
`[Character Name] + "all scenes" + [Title] + [quality tag]`

Examples:
- `Thanos all scenes Infinity War Endgame 4K`
- `Joel all scenes The Last of Us Part 1 4K`
- `Light Yagami all scenes Death Note 1080p`

### Recipe 6 — Abstract Concepts (Stock B-Roll)
`[Concept] + "stock footage" | "b-roll" | "motion graphics"`

Examples:
- `inflation motion graphics animation b-roll`
- `stock market crash cinematic b-roll 4K`
- `brain scan medical animation stock footage`

### Recipe 7 — Historical / Archival
`[Topic/Person/Event] + [Year] + "footage" | "archive" | "documentary"`

Examples:
- `JFK Dallas motorcade footage 1963 archive`
- `2008 financial crisis Lehman Brothers footage documentary`
- `Berlin Wall fall 1989 archival footage British Pathé`

### Recipe 8 — Reaction / Cutaway Shots
`[Character] + "reaction" + [Event] + [Title]`

Examples:
- `Jesse Pinkman reaction Walter White reveal Breaking Bad`
- `Daenerys reaction Red Wedding Game of Thrones`

## QUERY MODIFIERS (ADD WHEN NEEDED)

### Quality modifiers (almost always include one)
- `1080p` — safe default
- `4K` — when available
- `HD` — older content
- `60fps` — action-heavy scenes
- `remastered` — classic content
- `upscaled` — AI-upscaled newer uploads

### Format modifiers
- `raw` — unedited footage
- `no music` — original audio only
- `no commentary` — no YouTuber voiceover
- `no subtitles` / `no subs` — clean frame
- `full scene` — complete sequence
- `uncut` — uncensored version
- `extended` — extended cut

### Aesthetic modifiers (when cinematic output needed)
- `cinematic` — color-graded uploads
- `edit` — aesthetic fan edit
- `AMV` — for anime
- `tribute` — often higher-quality fan cuts

## COMMON QUERY FAILURES (AND HOW TO FIX THEM)

### Failure 1 — Too generic
- Bad: `Batman scene`
- Fix: Add film identifier + specific scene. `Batman The Dark Knight interrogation scene 1080p Joker`

### Failure 2 — Misspelling character / show names
- Always use exact canonical spelling. `Daenerys` not `Danerys`. `Hisoka` not `Hisuka`. `Gus Fring` not `Gus Frink`.

### Failure 3 — Missing source disambiguation
- Bad: `Spider-Man final battle` (which Spider-Man? There are 8+ films.)
- Fix: `Spider-Man No Way Home final battle three Spider-Men 4K`

### Failure 4 — Using plot-spoiler terms that haven't propagated
- If a scene is very recent, fans may not yet tag it with its "known" name. Add episode numbers or air-date descriptors.

### Failure 5 — Forgetting the aspect ratio / resolution filter
- For a 4K cinematic edit, specifying `4K` or `2160p` filters out 360p uploads

## GOOGLE SEARCH MODIFIERS (for wider-net searching)

When YouTube search isn't enough, use Google search with these operators:

- `site:youtube.com [query]` — restrict to YouTube
- `site:reddit.com [show name] scene pack` — find Reddit threads pointing to clips
- `"[exact phrase]"` — force exact match
- `filetype:mp4 [query]` — rarely works but occasional wins
- `[query] after:2024-01-01` — filter by recency
- `[query] -shorts` — exclude YouTube Shorts

## WHEN YOUTUBE FAILS — ESCALATION LADDER

Try in this order:

1. **YouTube direct** (with editor-grade query)
2. **YouTube + channel filter** (`@channelname [query]`)
3. **Reddit r/scenepacks** + show-specific subs
4. **Google site:youtube.com** with exact-match quotes
5. **Twitter/X** with `filter:native_video`
6. **Bilibili** (especially for anime and Asian cinema)
7. **Archive.org** (for pre-1970s and public-domain content)
8. **Vimeo** (for student/film-school uploads)
9. **Telegram scene-pack channels** (private, search manually)
10. **Screenshot → Google reverse image search** → follow the trail

## FAST TIPS

- **Paste episode name if you know it.** `Breaking Bad Face Off` narrows to ~500 results instead of millions.
- **Two queries always beat one query.** Give the user a broad query AND a narrow query.
- **Quote the iconic line.** `"I am the one who knocks"` in quotes often lands the exact scene.
- **Year helps for ambiguous titles.** `Joker 2019` vs `Joker 2008` vs `Joker 1989`.
- **Channel handles change.** If a channel name doesn't land hits, try the creator's actual name instead.
