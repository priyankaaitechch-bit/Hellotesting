# 01 — YOUTUBE SOURCING DATABASE

Channels and source ecosystems by niche. CLIP HUNTER uses this silently to recommend "backup channels" when a direct YT URL isn't available.

---

## VIDEO GAMES

**Tier 1 (primary):**
- @GameMovies — full "game movies" (all cutscenes), most AAA titles
- @ZanarAesthetics — 4K cutscene compilations, heavy PS4/PS5
- @CutscenesCentral — older/retro game cutscenes
- @BossFightDatabase — boss fights + story sequences

**Tier 2 (official studios):**
- @PlayStation, @Xbox, @NintendoAmerica, @NaughtyDog, @RockstarGames, @FromSoftware, @CDPROJEKTRED, @SquareEnix, @Ubisoft

**Tier 3 (niche):**
- @TheMediaKnightOfficial, @SlyFlySays, @Shirrako (Rockstar games)

---

## HOLLYWOOD FILM (MODERN)

**Tier 1:**
- @MOVIECLIPS (Fandango licensed clips — search first for any major film)
- @IMDb, @RottenTomatoesTRAILERS

**Tier 2 (studios):**
- @SonyPictures, @warnerbrospictures, @UniversalPictures, @DisneyStudios, @ParamountPictures, @Lionsgate, @A24, @FocusFeatures, @NEONrated

**Tier 3 (scene packs):** Volatile fan channels — use search pattern `[Film] scene pack`. Reddit r/scenepacks is the best crowdsourced index.

**Tier 4 (analysis channels with clean clips):**
- @Nerdwriter1, @LessonsFromTheScreenplay, @TheCinemaCartography, @Filmdicted

## ANIME

**Official:**
- @Crunchyroll (licensed anime clips)
- @ToeiAnimationOfficial (Dragon Ball, One Piece)
- @mappa_info
- @ShueishaInc

**Raw clip & twixtor:** Volatile — use search patterns:
- `[Anime] [Character] [scene] raw 1080p`
- `[Anime] twixtor [character] 4K`

**Non-YouTube (critical for anime):**
- Bilibili.com (Chinese fan mirrors — vast)
- Weibo video, iQIYI, Niconico (Japan)

**Communities:** Reddit r/animeedit, Twitter/X (`[anime] twixtor` accounts)

## AI VIDEO GENERATION (last resort)

- Runway Gen-3 Alpha — cinematic motion, short clips
- Kling AI — strong motion, longer clips
- Google Veo 3 — high fidelity
- Minimax (Hailuo) — fast iteration
- Luma Dream Machine — abstract motion
- Pika Labs — faster, lower fidelity

**Prompt anatomy:** `[shot type] + [camera movement] + [subject + clothing/action] + [lighting] + [setting] + [art style / film reference] + [mood] + [aspect ratio] + [duration]`

## META-SEARCH (when direct YT search fails)

1. Reverse image search a known frame → Google Lens / Yandex / TinEye
2. Reddit community crowdsourcing
3. Twitter/X `filter:native_video` search
4. Facebook public page video search
5. Vimeo (student/film-school uploads)
6. Dailymotion (takedown-resistant European mirror)
7. Telegram scene-pack channels (search manually in Telegram)
