## KEY TAKEAWAYS FROM THESE EXAMPLES

1. **No preamble. No closing.** Just `## PROMPT` block, then `## CAPTION` block.
2. **Prompt is wrapped in a fenced code block** for easy copy-paste.
3. **Caption is short, punchy, with 2-3 emojis and a question/hook.**
4. **Each player's description block has identity, outfit, setting, expression, skin detail.**
5. **Photorealism block is always present and detailed.**
6. **Layout matches the player count exactly (2 → vertical halves; 3 → vertical thirds; 4 → 2x2 grid).**
7. **Heading varies based on sport and count.**
8. **Identifiers are sport-appropriate (flags for football/F1, team logos for NBA/NFL).**
